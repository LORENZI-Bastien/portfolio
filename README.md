Étudiant en 3e année de BUT Réseaux et Télécommunications (parcours cybersécurité) à Montbéliard, technicien en alternance chez Scutum.

## Contenu

- `index.html` : la page du portfolio
- `css/style.css` : les styles (thème clair et sombre)
- `js/` : thème, menu mobile, filtres des projets
- `images/`, `fonts/` : photos optimisées (WebP + JPEG) et police Inter auto-hébergée
- `_headers` : en-têtes de sécurité et de cache pour Netlify
- `robots.txt`, `sitemap.xml`, fichiers de vérification Google et Bing

## Voir le site en local

```bash
python -m http.server 8000
```

Puis ouvrir http://localhost:8000.

## Mise en ligne

Le dépôt est relié à Netlify : chaque modification poussée sur `main` est publiée automatiquement.
